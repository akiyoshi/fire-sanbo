## 2. 評価方法

### 2.1 採点スケール（0–10）

各ギャップに対して以下の3軸で評価：

- **影響度** — 成功率／最終資産／実効税率の典型ケースでの定量変化
- **実装コスト** — エンジン変更行数、テスト追加、UI 配線
- **行動可能性** — ユーザーが今日／今月／今年に動ける具体性

### 2.2 採用基準

`Priority = 影響度 × 行動可能性 / 実装コスト` を概算し、上位を P0–P2 に配置。`DESIGN.md` の **過剰機能を避ける** メタ原則に従い、Priority < 1.0 は **凍結候補**として記録のみ。

## 5. 主要項目の実装スケッチ

### 5.1 T-2 iDeCo × 退職金の 5/19年ルール

**問題:** 現行は `idecoYearsOfService` を一括 / iDeCo 取り崩し時に毎回適用しているが、退職所得控除は受給年が同じだと**重複期間が控除から差し引かれる**（所得税法施行令70条）。「退職金を先に受け取り、その後5年以内にiDeCo一時金」だと控除が圧縮される。

**正しいルール（2026年現在）:**
- iDeCo一時金 → 退職金: iDeCo受給年から **5年（2027年税制改正で19年見込み）** 経過していれば、退職金の勤続年数控除は重複期間を引かずにフル使用可
- 退職金 → iDeCo一時金: 退職金受給年から**19年**経過していればiDeCo側もフル使用可

**型変更案:** `src/lib/simulation/types.ts`

```typescript
export interface RetirementBonusInput {
  amount: number;
  yearsOfService: number;
  /** 受給年齢（省略時は retirementAge） */
  receiveAge?: number;
}

export interface IdecoConfig {
  /** 一時金受給年齢（60–75） */
  lumpSumAge: number;
  /** 加入年数（拠出していた年数） */
  yearsOfContribution: number;
  /** 一時金 / 年金 / 併用 */
  receiveMode: "lumpSum" | "pension" | "mixed";
  /** 併用時の一時金比率（0–1） */
  lumpSumRatio?: number;
}
```

**エンジン追加:** `src/lib/tax/engine.ts`

```typescript
/**
 * 退職金とiDeCo一時金の重複期間を考慮した実効勤続年数を返す
 * - 受給年差が 5年（or 19年）以下のとき、後発側の控除年数から重複期間を引く
 */
export function calcEffectiveYearsForLumpSum(
  primaryReceiveAge: number,
  primaryYears: number,
  secondaryReceiveAge: number,
  secondaryYears: number,
  ruleYears: 5 | 19 = 5,
): { primary: number; secondary: number } {
  const gap = Math.abs(primaryReceiveAge - secondaryReceiveAge);
  if (gap >= ruleYears) {
    return { primary: primaryYears, secondary: secondaryYears };
  }
  // 重複期間を後発側から控除
  const overlap = Math.min(primaryYears, secondaryYears) - gap;
  // ... 実装詳細は所得税法基本通達30-12（重複勤務期間）に従う
}
```

## 付録 A: 用語集

- **5/19年ルール** — 退職所得控除の重複期間に関する所得税法施行令70条の通称。iDeCo一時金と退職金を別々に受給する際、受給年の差が5年（19年）以上あれば勤続年数控除を重複期間を引かずにフル使用できる。
- **シーケンスリスク（順序リスク）** — 同じ平均リターンでも、退職直後にマイナスが集中すると資産枯渇確率が大幅に上がる現象。
- **SWR (Safe Withdrawal Rate)** — 一定の成功率（典型的に95%）で資産が枯渇しない年間取り崩し率。Bengen の4%ルール（米国・30年）が起点。
- **ガードレール戦略** — Guyton-Klinger による動的取り崩し戦略。資産が想定経路から ±20% 乖離したときに支出を ±10% 調整する。
- **Bond Tent** — 退職5年前から退職後5年にかけて債券比率を一時的に高め、シーケンスリスクを抑える戦略。
- **任意継続健保** — 退職後最大2年間、退職前の健保に加入し続けられる制度。保険料は労使折半なしで全額自己負担。
